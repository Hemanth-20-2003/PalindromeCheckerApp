# PalindromeCheckerApp

## UC-05: Stack-Based Palindrome Checker

This feature checks whether a given string is a palindrome using a stack data structure. The program pushes all characters of the string into the stack and then pops them to reverse the order. The reversed characters are compared with the original string to validate whether it reads the same forward and backward. This demonstrates the LIFO (Last In First Out) behavior of stacks for solving problems like palindrome checking.
