# PalindromeCheckerApp

## UC6: Queue + Stack Palindrome Checker
This use case demonstrates palindrome validation using two data structures: Queue and Stack. Characters from the input string are inserted into both structures. The queue follows FIFO (First In First Out) and the stack follows LIFO (Last In First Out). By removing characters from the front of the queue and the top of the stack and comparing them, the program determines whether the string is a palindrome.
