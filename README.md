# PalindromeCheckerApp

## UC10: Case-Insensitive & Space-Ignored Palindrome Checker
This use case checks whether a string is a palindrome while ignoring spaces and letter case. The input string is first normalized by removing spaces and converting all characters to the same case using string preprocessing techniques such as regular expressions. After normalization, the palindrome validation logic is applied to determine whether the processed string reads the same forward and backward.
